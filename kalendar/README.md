# Rozpis směn – Juri

`juri-zari-2026.ics` – 17 směn ze sloupce **Juri** v rozpisu ZÁŘÍ 2026.

| | |
|---|---|
| Denní (D) | 1., 3., 4.*, 11., 12., 13., 14., 30. |
| Noční (N) | 7., 8., 16., 17., 21., 22., 25., 26., 27. |

\* 4. 9. je v rozpisu dopsáno ručně na přelepce – čitelné jako „D" nebo „R". V kalendáři je označeno otazníkem.

Časy: **denní 6:00–18:00**, **noční 18:00–6:00** (končí následující den), časové pásmo Europe/Prague.

## Import do Apple Calendar
1. Otevři `.ics` (dvojklik na Macu / v Souborech na iPhonu).
2. Vyber kalendář, do kterého se má rozpis přidat.
3. Potvrď import.

## Změna časů směn
Uprav konstanty `DEN` a `NOC` v `generate_juri.py`, pak spusť `python3 generate_juri.py`.
